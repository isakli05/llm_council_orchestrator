# 08 — Security

Inherited as-is: realpath containment (`storage/paths.ts`), O_EXCL locks, atomic staged writes, loopback-only clarification server + token-in-fragment + CSP, scrubbed exec (check path only), secrets env-by-name, doctor never printing values, BaseUrl guards. New in V1 (all tested):
- **Untrusted target**: default-deny by NAME before any read (`.env*`, keys, `id_rsa*`, credentials/secrets, `*.pem/p12/pfx`, archives never expanded); vendored/VCS/generated dirs skipped; symlinks never followed (escape and in-repo alike — fail-closed); binary sniff (NUL ≤8KiB); per-file/corpus caps → blocked diagnostics with sizing guidance; `.gitignore` NOT treated as security.
- **Anchors**: recomputed hashes; realpath containment; traversal/absolute/backslash/directory refusal; symlink escape refusal (in-repo links resolve — documented); wrong-root never verifies.
- **Prompt hygiene**: bounded context (items/chars/lines/files); manifest-contained slice reads only; secret redaction before any prompt inclusion (private keys, bearer tokens, AKIA keys, sk_-style, secret-shaped assignments — key NAME kept; markers never re-matched); ALL repo content inside explicit untrusted-data fences; standing rules (data-not-instructions, no tools/execution/write) OUTSIDE the fence; canary tests prove single-occurrence containment and redaction; secrets never persisted (analysis records carry digests, not prompts).
- **Trust gates**: snapshot staleness refuses analyze/plan (visible transition; no silent auto-refresh before paid calls); parity/anchor gates refuse planning; strategy/parity DROP human-only.
- **MCP**: consent digest for the single paid tool (zero calls without it — tested); no exec; no Graphify proxying; Graphify = trusted executable, untrusted parsed output (defensive reader; version/capability probe; incompatible/absent/malformed fail closed).
