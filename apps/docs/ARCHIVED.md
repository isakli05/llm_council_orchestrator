# ARCHIVED — historical design notes

These are the design documents of the legacy LLM Council system (orchestrator,
indexer, MCP bridge, role system). They describe the architecture that was
replaced by the spec-core pivot and are kept only as source history — nothing
here is a supported or runnable system.

The active product is **`lco-spec`** (`packages/spec-core`); its documentation
lives in [packages/spec-core/README.md](../../packages/spec-core/README.md) and
the root README section
["Legacy (archived) — do not run"](../../README.md#legacy-archived--do-not-run).
